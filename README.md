# জমা-খরচ (Joma Khoroch) • GitHub Pages ওয়েব সংস্করণ

এই ফোল্ডারে থাকা ফাইলগুলো দিয়ে আপনি GitHub-এ সম্পূর্ণ ফ্রি ও আজীবনের জন্য আপনার **জমা-খরচ** ওয়েব অ্যাপটি হোস্ট করতে পারবেন।

---

## 📁 ফাইল পরিচিতি
- `index.html` — প্রধান ওয়েব পেজ (Date-to-Date রিপোর্ট, মাসিক বাজেট সতর্কতা কার্ড, এন্ট্রি ফর্ম ও সেটিংস সহ)।
- `style.css` — মোবাইল ও কম্পিউটারের জন্য আধুনিক রেসপন্সিভ ডিজাইন ও এমারেল্ড গ্রিন থিম।
- `app.js` — অফলাইন লোকাল ডেটাবেজ, মাসিক বাজেট ট্র্যাকিং, UPI অনলাইন পেমেন্ট, স্বয়ংক্রিয় পুনরাবৃত্তিমূলক হিসাব ও CSV এক্সপোর্ট ইঞ্জিন।
- `manifest.json` — মোবাইলে হোম স্ক্রিনে অ্যাপের মতো ইনস্টল (PWA) করার কনফিগারেশন।

---

## 🚀 GitHub Pages-এ লাইভ ওয়েবসাইট বানানোর স্টেপ-বাই-স্টেপ গাইড

### পদ্ধতি ১: নতুন রিপোজিটরি তৈরি করে (সহজতম ও প্রস্তাবিত)

1. আপনার ব্রাউজারে [GitHub.com](https://github.com)-এ লগইন করুন।
2. উপরে ডানদিকের **`+`** আইকনে ক্লিক করে **"New repository"** নির্বাচন করুন।
3. **Repository name** ঘরে লিখুন: `joma-khoroch` (বা আপনার পছন্দের নাম)।
4. এটি **Public** রাখুন এবং নিচে থাকা **"Add a README file"** অপশনটিতে টিক দিন।
5. সবুজ **"Create repository"** বাটনে চাপুন।
6. এবার রিপোজিটরির ভেতরের **"Add file"** বাটনে ক্লিক করে **"Upload files"** নির্বাচন করুন।
7. এই `web` ফোল্ডারের ভেতরের **৪টি ফাইল** (`index.html`, `style.css`, `app.js`, `manifest.json`) টেনে এনে (Drag & Drop) ছেড়ে দিন অথবা সিলেক্ট করে দিন।
8. নিচে থাকা সবুজ **"Commit changes"** বাটনে ক্লিক করুন।
9. এবার রিপোজিটরির উপরের মেন্যু থেকে **Settings** ট্যাবে যান।
10. বাঁদিকের সাইডবার থেকে **"Pages"** অপশনে ক্লিক করুন।
11. **Branch** ড্রপডাউনে `None` এর জায়গায় **`main`** নির্বাচন করুন, ফোল্ডার `/ (root)` রেখে **"Save"** বাটনে চাপুন।
12. ১-২ মিনিট অপেক্ষা করে পেজটি রিফ্রেশ করলে উপরে আপনার লাইভ ওয়েবসাইটের লিংক দেখতে পাবেন:
    `https://ajoy720.github.io/joma-khoroch/`

### পদ্ধতি ২: আপনার আগের `_deposite_expence` রিপোজিটরিতে আপডেট করতে চাইলে

1. GitHub-এ গিয়ে আপনার পূর্বের রিপোজিটরি `_deposite_expence`-এ প্রবেশ করুন।
2. **"Add file"** -> **"Upload files"**-এ যান।
3. নতুন `index.html`, `style.css`, `app.js` ফাইলগুলো আপলোড করে **"Commit changes"** করে দিন।
4. কয়েক মিনিটের মধ্যেই আপনার পুরনো লিংক `https://ajoy720.github.io/_deposite_expence/index.html`-এ নতুন ফিচারগুলো চালু হয়ে যাবে।
