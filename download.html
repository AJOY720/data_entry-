🌐 জমা-খরচ ওয়েব ফাইল ডাউনলোড কেন্দ্র

মাসিক বাজেট সতর্কতা ও UPI অনলাইন পেমেন্ট সহ GitHub Pages-এ লাইভ ওয়েবসাইট চালু করুন

📥 ফাইল ডাউনলোড অপশন রেডি

নিচের যেকোনো বাটনে ক্লিক করে সরাসরি ফাইলটি সেভ করুন:

📦 ডাউনলোড সম্পূর্ণ জিপ ফাইল (joma_khoroch_web.zip) 📄 একক ফাইল ডাউনলোড করুন (index.html — No Unzip Needed)

🚀 GitHub Pages-এ যেভাবে লাইভ করবেন (মাত্র ২ মিনিট)

  1. GitHub.com-এ গিয়ে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: joma-khoroch)।
  2. Add file ➔ Upload files-এ গিয়ে জিপ ফাইল থেকে আনজিপ করা ফাইলগুলো (অথবা সরাসরি একক index.html) আপলোড করে Commit changes বাটনে চাপুন।
  3. রিপোজিটরির Settings ➔ Pages-এ যান।
  4. Branch-এ main সিলেক্ট করে Save-এ ক্লিক করুন।
  5. ১-২ মিনিটের মধ্যে আপনার ফ্রি ওয়েবসাইট লাইভ হয়ে যাবে!

✨ নতুন যা যা যুক্ত করা হয়েছে

  • মাসিক বাজেট সতর্কতা: হোম স্ক্রিনে প্রগ্রেস বার, খরচ ৮০% পার হলে হলুদ ওয়ার্নিং এবং ১০০% পার হলে লাল ওভার-বাজেট অ্যালার্ট।
  • UPI অনলাইন পেমেন্ট: বিকাশ-এর স্থানে "UPI অনলাইন" ডিফল্ট হিসেবে যুক্ত।
  • Date-to-Date রিপোর্ট: নির্দিষ্ট যেকোনো দুই তারিখের মধ্যবর্তী খরচের হিসাব।
  • স্বয়ংক্রিয় রিকারিং: প্রতি মাসের নির্দিষ্ট দিনে স্বয়ংক্রিয়ভাবে জমা বা খরচের এন্ট্রি যোগ।
